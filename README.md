# ProduktKatalog E-handel

Ett webbaserat e-handelssystem där produkter kan hanteras och presenteras för användare.  
Projektet är byggt med **ASP.NET Core MVC** och **SQL Server** för datalagring.

 ✨ Funktioner
- Visa produkter och kategorier
- Söka och filtrera produkter
- Lägga till, redigera och ta bort produkter (administratör)
- Responsiv design för både desktop och mobil
- Databaskoppling med Entity Framework Core

 👥 Roller och behörigheter
- **Besökare**  
  - Kan bläddra bland produkter och se detaljer.
- **Registrerad användare**  
  - Kan skapa konto, logga in och hantera enklare interaktioner (t.ex. profilinställningar).
- **Administratör**  
  - Har full behörighet att hantera produkter, kategorier och användare.

🛠️ Teknologier
- C# / .NET 8
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML5 / CSS3
- Bootstrap (responsiv design)
